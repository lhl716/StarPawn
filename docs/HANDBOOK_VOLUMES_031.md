The metals collection index has two pages and the jade index one page. No content is truncated. Each volume contains one explanation page followed by at most four pages with two paired illustrations per page. The inspection shortcut selects the volume by public product family, including for intact items; it does not select by hidden defect or grade.

`HandbookTemplates` pins the fixed examples and `HandbookFamilies` pins the product families in each new definition. Content validation rejects oversized books, missing/duplicated examples, cross-category families, and defect-bearing families without complete coverage. A new extension family with no authored defects may use the collection index. Owning one new volume grants access only to that volume; an old anthology preserves its existing category-wide access.

Physical purchase, native ownership, save identity, book reading and the existing eight-slot organizer use the same item transaction path as other equipment. More books do not enlarge an existing organizer or change its occupied cells.

For future 0.4 production, create additional category-specific volumes rather than extending any book past five pages or shrinking text. New cover drawings can reuse the frozen 1 x 1 footprint, 64 x 64 inventory canvas and 384 x 256 inspection canvas. Reader pages remain 440 x 616 with runtime text.
