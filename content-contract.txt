StarPawn content / inspection contract (pure netstandard2.1; all class members are public serializable fields)
UI must display Catalog.PublicFacts(asset), never hidden truth fields on ItemDefinition / AssetRecord. Quote.MaterialValue and CraftPremium split material and workmanship. RecoveryValueConfirmed=false means a claimed estimate, never a verified guarantee.
All coordinates are normalized in the actual visible image rectangle, x left-to-right, y top-to-bottom. Letterbox margins must not be mapped into the artwork.
Only actual deal termination calls EndEncounter; closing the inspector preserves customer+asset encounter, misses, lock and selected evidence. Auto-discovery is restricted to observable current view.
All CashCost actions require Changed=true then a single atomic root-state debit+save. Root must clone state or rollback on native debit/persistence failure. Transactions use AssetQuote snapshot and IsCurrent before commit.
